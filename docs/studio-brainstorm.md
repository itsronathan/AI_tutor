# Studio Brainstorm starter

Architecture students can open `/studio` from Home or the sidebar, paste their
semester assignment brief, and record initial interests and an intended experience.
Optional questions can stay blank. Saving shows a summary and stores one draft per
user ID (or guest) in this browser. Drafts do not sync to the backend; guest drafts
are shared on that browser. Local storage is not a security boundary.

The three sketching exercises are static prompts, explicitly labeled as general
exercises. This milestone does not call an AI model or process uploaded files.
The starter page content is English; its navigation label supports the existing
four locales.

## Try it

1. Start the frontend using the root README instructions and open `/studio`.
2. Paste a brief, optionally add interests, and select **Save project draft**.
3. Reload and confirm the notes return. Edit them and save again.
4. On a narrow screen, the exercise cards should stack beneath the form.
